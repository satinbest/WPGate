# فرآیند انتشار و سیاست نسخه‌بندی WPGate

[English](../en/release-process.md) | [فارسی](release-process.md)

این سند مراحل استاندارد مهندسی انتشار و مدیریت نسخه‌ها را در پروژه WPGate تبیین می‌کند.

---

## 🏷️ الگوی نسخه‌بندی (Versioning Scheme)

پروژه WPGate دقیقاً از استاندارد [نسخه‌بندی معنایی نسخه 2.0.0 (SemVer)](https://semver.org/):
- **بزرگ / MAJOR (`x.0.0`):** تغییرات بنیادین معماری ناسازگار با نسخه‌های قبلی یا حذف APIهای عمومی.
- **کوچک / MINOR (`0.x.0`):** افزودن قابلیت‌های جدید با حفظ سازگاری با نسخه‌های پیشین، بهینه‌سازی‌های عمده یا پیش‌فرض‌های جدید.
- **وصله / PATCH (`0.0.x`):** رفع باگ‌ها، اصلاحات امنیتی و بروزرسانی‌های پایدارساز سازگار با نسخه‌های قبلی.

---

## 📋 چک‌لیست تضمین کیفیت پیش از انتشار (Pre-Release QA)

پیش از ایجاد هرگونه تگ نسخه جدید در گیت یا درخواست ادغام در شاخه `main`، بررسی‌های زیر الزامی است:

۱. **اعتبارسنجی نحوی کدهای PHP:**
   ```bash
   find mu-plugin-package theme-package tests -name "*.php" -exec php -l {} \;
   ```
۲. **اجرای کامل مجموعه آزمون‌های خودکار:**
   ```bash
   php tests/run-tests.php
   ```
   *شرط الزامی: قبولی ۱۰۰٪ تمامی آزمون‌ها بدون حتی یک خطا.*
۳. **تطابق دقیق شماره نگارش در تمام فایل‌ها:**
   - `bootstrap.php` (ثابت `WPGATE_CORE_VERSION`)
   - `wpgate-loader.php` (هدر `Version`)
   - `CHANGELOG.md` و `CHANGELOG-FA.md`
   - `RELEASE-NOTES.md` و `RELEASE-NOTES-FA.md`
   - نام فایل‌های فشرده بسته‌ها
۴. **صحت‌سنجی ساختار بسته‌های ZIP:**
   اطمینان از قرار گرفتن فایل لودر `wpgate-loader.php` مستقیماً در ریشه فایل فشرده پکیج MU-Plugin.

## 🚀 مراحل انتشار نسخه جدید

۱. **بررسی کامیت‌ها و شاخه‌ها:** اطمینان از قرار داشتن تغییرات در شاخه توسعه یا فیچر مورد نظر.  
۲. **ایجاد درخواست ادغام (Pull Request):** ایجاد پول ریکوئست به مقصد شاخه `main`.  
۳. **تاییدیه مدیر پروژه:** اخذ تایید نهایی از مدیر پروژه (Project Manager / Product Owner).  
۴. **ثبت تگ نسخه در گیت:**
   ```bash
   git tag -a v0.1.1 -m "Release v0.1.1"
   git push origin v0.1.1
   ```
۵. **اجرای خودکار گردش‌کار گیت‌هاب (GitHub Actions):**
   گردش‌کار `release.yml` با ایجاد تگ فعال شده، بسته‌های زیپ را بیلد کرده، هش SHA-256 را محاسبه و نسخه رسمی را به همراه یادداشت‌های انتشار منتشر می‌کند.
